## System Information

* **Hostname:** The hostname of the virtual appliance.
* **IP Address:** The IP address of the virtual appliance that is configured either via DHCP or a static configuration.
* **Netmask:** The subnet mask of the virtual appliance that is configured either via DHCP or a static configuration.
* **Gateway:** The default gateway of the virtual appliance that is configured either via DHCP or a static configuration.
* **Primary DNS Server:** The primary DNS server of the virtual appliance that is configured either via DHCP or a static configuration.
* **Secondary DNS Server:** The secondary DNS server of the virtual appliance that is configured either via DHCP or a static configuration.
* **Platform:** The virtualization platform or cloud the appliance is running on.
* **Appliance Version:** The version of the helper virtual appliance.


## Configure Network Settings

* **IP Addressing:** Whether to use DHCP or a static IP Addresss
* **IP Address (Static Only):** The IP address of the virtual appliance that is configured either via DHCP or a static configuration.
* **Netmask (Static Only):** The subnet mask of the virtual appliance that is configured either via DHCP or a static configuration.
* **Gateway (Static Only):** The default gateway of the virtual appliance that is configured either via DHCP or a static configuration.
* **Primary DNS Server (Static Only):** The primary DNS server of the virtual appliance that is configured either via DHCP or a static configuration.
* **Secondary DNS Server (Static Only):** The secondary DNS server of the virtual appliance that is configured either via DHCP or a static configuration.
